# Power BI Dashboard

The final interactive Power BI dashboard is included in this folder:

- `dublin_bikes_operations_dashboard.pbix`

The dashboard presents the validated operational findings from the April 2026 Dublin Bikes station-status analysis, including:

- Network KPI cards for observations, stations, empty rate and full rate
- Hourly near-empty and near-full availability risk
- Top rebalancing-priority stations
- Geographic station-priority mapping
- Station-level operational detail
- Interactive weekday/weekend and station filters

A portfolio screenshot is available at `images/power_bi_dashboard.png`.

The `.pbix` file is retained so reviewers can inspect the Power BI data model, DAX measures and interactive report design.
