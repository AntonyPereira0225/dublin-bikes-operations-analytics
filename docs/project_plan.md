# Project Plan

## Objective
Identify station-level availability patterns and operational pressure points that can support better bike-rebalancing decisions.

## Planned Stages
1. Obtain official Dublin Bikes historical station data.
2. Profile and clean the raw data in Python.
3. Engineer operational features and risk flags.
4. Export an analysis-ready dataset.
5. Analyse patterns in SQL.
6. Build Power BI measures and dashboards.
7. Summarise findings and recommendations.
